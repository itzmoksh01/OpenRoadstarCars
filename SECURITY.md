# Security policy

## Supported versions

The `main` branch is the supported development line. This is a static browser game and does not currently process accounts, payments or private user data.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use a private GitHub Security Advisory for this repository when available. If that channel is not enabled, contact the repository maintainer privately through GitHub with the subject `Open Roadster Cars security report`.

Include reproduction steps, affected browsers or devices, impact and any proposed mitigation. Do not include secrets or personal data in a report.

## Project boundaries

Do not commit API keys, credentials, private signed asset URLs, user leaderboard exports or unverified third-party assets. The local leaderboard is browser-local and is not treated as a trusted competitive record.
